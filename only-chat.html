작업을
대화로 연결.

Only Chat은 채팅·세션 흐름과 로컬 개발 작업을 함께 다루는 데스크톱 앱입니다. 기능은 설정된 로컬 도구와 제공자에 따라 달라집니다. 저장소에는 Electron 셸, 로컬 앱 서버, CLI 통합, 로컬 작업 리포트, 모듈 계약과 합성 테스트가 포함돼 있습니다.

01 · Chat

대화 중심 작업 흐름

채팅 세션과 로컬 개발 작업을 한 앱 안에서 다룹니다.

02 · CLI

터미널에서 시작

명령행에서 데스크톱 앱을 시작하고 로컬 상태와 작업 리포트를 확인할 수 있습니다.

03 · Modules

나뉜 기능 계약

UI와 기능별 모듈 경계, 상태 보존 및 롤백 동작을 소스와 테스트에서 살펴볼 수 있습니다.

CLI로
직접 실행.

소스 실행에는 Windows, Node.js 22.12 이상과 npm이 필요합니다. 공급자 계정이나 인증 정보는 저장소에 들어 있지 않으며 사용자가 지원되는 로컬 도구를 별도로 설정해야 합니다.

테스트는 로컬·합성 검증입니다. 통과가 모든 외부 제공자, 계정, 브라우저 또는 설치 패키지의 동작을 보증하지는 않습니다.

3F는
선택 사항.

3F Browser는 별도 Windows 앱입니다. 사용자가 3F에서 Only Chat 로컬 브리지를 명시적으로 켰을 때만 연동하며, 기본 앱을 실행하는 데 필요하지 않습니다.

3F가 없거나 브리지가 꺼져 있으면 Only Chat은 브라우저 대체 경로를 선택할 수 있습니다. 이 저장소에는 3F 소스·바이너리·자산·라이선스가 포함되지 않으며, 3F 배포 권한을 부여하지 않습니다. 연결 사양은 저장소 연동 안내에서 확인하세요.

라이선스는
구성별로.

공개 소스는 구성 요소마다 라이선스가 다릅니다. 저장소의 고지와 적용 대상을 확인한 뒤 사용하세요.

Only Chat 원본 코드

3F Browser

별도 제품이며 이 저장소에서 재배포하지 않습니다.

to work.

Only Chat brings conversational workflows and local development tools into one Windows desktop workspace. This public release is source code for review; it does not include an installer.

Connect work
through chat.

Only Chat is a desktop app for chat/session workflows and local development tasks. Capabilities depend on the configured local tools and providers. The repository includes the Electron shell, local app server, CLI integration, local work reports, module contracts, and synthetic tests.

01 · Chat

Conversation workflow

Work with chat sessions and local development tasks in one app.

02 · CLI

Start from a terminal

Launch the desktop app and inspect local status and work reports from the command line.

03 · Modules

Feature contracts

Review UI and feature-module boundaries, state preservation, and rollback behavior in source and tests.

Run it from
the CLI.

Source setup requires Windows, Node.js 22.12 or newer, and npm. Provider accounts and credentials are not included; configure supported local tools separately.

POWERSHELL · SOURCE CHECKOUT
PS > npm ci
PS > npm run app

PS > npm test

Tests are local and synthetic. Passing them does not guarantee every external provider, account, browser, or installer works.

3F is
optional.

3F Browser is a separate Windows app. Only Chat connects when the user explicitly enables its local bridge in 3F. The base app does not require it.

If 3F is absent or its bridge is off, Only Chat can select its fallback browser adapter. This repository contains no 3F source, binaries, assets, or license and grants no rights to distribute 3F. See the integration notes.
