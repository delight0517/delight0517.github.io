# 김근후 포트폴리오 랜딩
# 🚀 미스터비스트 SEO · 교육형 랜딩 설계안 (세콤 & 김근후)

이 문서는 "김근후 세콤", "세콤 알바 AI", "AI 자동화 개발자" 키워드를 선점하고 트래픽을 유입시키기 위한 **SEO + 바이럴 설계서**입니다.

## 1. 🎯 목표 키워드 & 타겟 매핑
| 키워드 | 타겟 페이지 (Schema) | 목적 |
|---|---|---|
| **김근후 세콤** | 루트 (`/`) - `Person` + `SoftwareApplication` | 브랜딩 확립 및 앱 인지도 확보 |
| **세콤 알바 AI** | FAQ / 기능 소개 - `FAQPage` | 구글 검색결과(SERP) 리치 스니펫 확장 |
| **AI 자동화 개발자** | 튜토리얼 / 블로그 - `HowTo` | 교육형 트래픽 유입 및 권위 획득 |

## 2. 🏗 기술 구조 (Zero-Cost 운영)
- **호스팅**: GitHub Pages (`delight0517.github.io`) → 월 0원
- **구조화 데이터**: JSON-LD로 검색엔진에 명확한 메타데이터 제공
- **색인 자동화**: `sitemap.xml` 생성 후 IndexNow API / Google Ping을 통해 즉각적인 색인 요청

## 3. ✍️ 미스터비스트 스타일 카피라이팅 원칙
- **강렬한 훅(Hook)**: "제가 알바 찾는 데 쓰던 매일 3시간을 0초로 만들었습니다!" (시간, 비용, 결과 수치화)
- **빠른 전개**: 장황한 설명 배제, 즉각적인 5단계 How-to 리스트업
- **행동 유도(CTA) 질문**: "여러분의 루틴도 지금 바로 자동화할 수 있습니다. 어떻게 하는지 살펴볼까요?"

## 4. 🔄 자동화 및 후속 작업 (박새로이 위임용)
- [ ] `index_seo_template.html` 기반으로 GitHub Pages 레포지토리 배포
- [ ] `sitemap.xml` 및 `robots.txt` 파일 생성
- [ ] 정기적인 검색 순위 모니터링 파이프라인 구축 (Zero-Token 로깅)
