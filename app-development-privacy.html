익명 통계 안내

적용일: 2026년 9월 29일

이 페이지는 김근후의 앱 제작 안내 사이트가 방문 통계를 어떻게 다루는지 설명합니다. 통계 수집은 선택 사항이며, 동의하기 전에는 방문 이벤트를 보내지 않습니다.

동의한 경우 수집하는 통계

  • 브라우저에 저장되는 무작위 익명 방문자 ID
  • 방문한 페이지, 본 섹션, 문의 채널을 열거나 선택한 이벤트
  • 대략적인 국가와 광역 행정 지역 코드(Cloudflare의 IP 기반 추정치)
  • 유입 사이트의 도메인, UTM 출처·매체·캠페인, 데스크톱/모바일 구분

이름, 전화번호, 이메일 주소, 메시지 내용, IP 주소 자체는 이 사이트의 분석 기록에 저장하지 않습니다. 지역은 대략적인 네트워크 기반 추정치이며 실제 위치와 다를 수 있습니다.

목적과 보관 기간

어느 지역과 유입 경로에서 페이지를 찾고 어떤 문의 동선을 살펴보는지 집계해 사이트를 개선합니다. 앱 제작 안내의 집계 기록은 최대 180일 뒤 만료되도록 보관합니다.

동의 변경

아래 버튼을 누르면 안내 페이지로 돌아가 통계 동의 여부를 바꿀 수 있습니다. 거부하거나 동의를 철회하면 이후 분석 이벤트 전송을 중단하고 브라우저에 저장한 익명 ID를 지웁니다.
