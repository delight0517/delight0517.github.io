수업 알리미 (Everytime Reminder)

대학생과 수강생을 위한 시간표 리마인더입니다. 과목명·강의실·교수명·요일·시간을 직접 등록하면 오늘 수업을 한눈에 확인하고, 수업 전 원하는 시간에 알림을 받습니다. 외부 서비스 없이도 시간표를 완성할 수 있습니다.

주요 기능

  • 수업 직접 추가 · 오늘 일정 · 주간 시간표 그리드
  • 일정 채팅으로 휴강·보강·쉬는 날을 말로 등록 (기본 규칙 파서, 선택적으로 무료 AI API 연동)
  • 수업 시작 전 사전 알림 · 홈 위젯
  • 표 붙여넣기 · 캘린더 연동 · 백업 폴더 복원
