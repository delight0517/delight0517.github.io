수업 알림 가이드

수업 시작 전에,
강의실까지 확인하기

수업 직전에 시간표를 다시 찾느라 서두르지 않도록, 수업별 알림을 미리 정해둘 수 있어요.

처음 설정하는 순서

  1. 수강신청 화면에서 시간표 표를 복사해 수업 알리미 채팅에 붙여넣습니다. 과목을 직접 추가해도 됩니다.
  2. 등록된 과목과 강의실을 확인하고, 알림을 받을 수 있도록 기기 알림 권한을 허용합니다.
  3. 수업 시작 30분·15분 전에 알림이 오도록 설정하고 필요한 경우 과목별로 조정합니다.
알림이 오지 않으면 앱 알림 권한, 과목의 알림 설정, 기기 집중 모드와 배터리 절약 설정을 확인해 보세요. 운영체제와 기기 설정에 따라 알림 표시 방식은 달라질 수 있습니다.

수업 알림 앱이 필요한 경우

시간표를 이미 다른 곳에서 관리하더라도 수업 직전 알림과 강의실 정보를 한 번에 확인하고 싶을 때 쓸 수 있습니다. 수업 알리미는 에브리타임과 제휴된 공식 앱이 아닙니다. 계정 없이 과목을 직접 등록할 수 있습니다.
