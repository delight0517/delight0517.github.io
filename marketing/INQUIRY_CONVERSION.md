# アプリ制作 문의 전환 개선 / 2026-10-03

## 변경

- 신청·기록·진행 상태를 정리하고 싶은 운영자의 문제를 첫 화면에서 설명한다.
- 한국 문의는 기존 공개 카카오톡 링크로 직접 연결한다. 이메일에는 현재 업무, 불편한 점, 희망 시기, 선택 예산을 미리 넣는다.
- 일본어는 동일한 구조의 이메일로 직접 연결한다. 포트폴리오 링크와 접근성 이름은 별도 선택자로 유지한다.
- 콘셉트 화면과 개인 프로젝트를 명시한다. 고객 납품, 매출, 계약 실적을 주장하지 않는다.
- 직접 링크도 동의한 브라우저에 한해 기존 contact:channel-click 이벤트를 기록한다. 문의 버튼 클릭은 문의 수신·계약·결제 완료가 아니다.
- 기존 시작 가격과 서면 견적·외부 이용료·환불 조건을 보존한다.

## 검증과 범위

- 최신 origin/main 4a4ce77을 기준으로 별도 체크아웃에서 작업한다. 기존 폴더의 미커밋 변경을 포함하지 않는다.
- Aside에서 한국어 실제 표시 및 일본어 번역·메일 목적지·본문·포트폴리오 링크를 확인했다. 메일은 발송하지 않았고 카카오톡 대화도 보내지 않았다.
- JavaScript 구문 검사 및 git diff --check를 수행한다. JSON-LD는 JavaScript로 실행하지 않고 JSON으로 검증한다.
- Impeccable 검사기는 HTML 분석 라이브러리가 없어 제한된 정규식 검사였다. 기존 폰트·동작·글로우 경고가 있어 전체 접근성·디자인 통과를 주장하지 않는다.
- 모바일 실기기·문의 수신·운영 통계 이벤트 수신은 미검증이다. 테스트 브라우저에서는 통계 수집을 거부해 실제 측정값에 테스트 클릭을 넣지 않는다.

## 측정

기간은 개선 페이지의 실제 배포일로부터 14일이다. Search Console의 확정된 페이지 노출/클릭, 동의한 브라우저의 문의 채널 클릭, 확인된 실제 문의를 분리한다. 표본이 작거나 수집 동의가 없는 방문은 0 수요로 단정하지 않는다. 경쟁 사이트 이용자 위치나 LLM 사이트 전체 요청량은 접근 권한 없이 확인할 수 없다.
