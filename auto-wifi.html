WHAT IT DOES

연결 상태를
보이는 정보로.

Wi-Fi 아이콘 하나로 알기 어려운 연결 품질을 실제 다운로드 측정과 간결한 연결 상태로 확인합니다.

01

요청할 때 직접 속도 측정

현재 Wi-Fi 인터페이스에 묶어 512 KiB 다운로드를 최대 세 번 수행합니다. 연결이 바뀌면 결과를 현재 네트워크 값으로 저장하지 않습니다.

02

속도와 인터넷 연결을 구분

링크 속도, 실제 다운로드 처리량, 인터넷 연결 상태는 서로 다른 값입니다. 앱은 측정한 다운로드 값만 실측 속도로 표시합니다.

03

핫스팟과 익숙한 Wi-Fi

macOS의 네트워크 경로 신호와 직접 선택한 설정으로 핫스팟을 구분합니다. 네트워크별 과거 평균은 장소 비교에 참고할 수 있습니다.

04

기기에 남는 짧은 기록

개별 측정 기록은 72시간 범위로 정리하고, 네트워크별 요약 평균은 로컬에 저장합니다. 위치 좌표를 수집하지 않습니다.

MEASUREMENT NOTES

무엇을
실측하나요?

완료된 측정 한 번은 최대 1.5 MiB의 다운로드 요청을 보냅니다. 측정 서버는 Cloudflare speed test endpoint입니다. 이 값은 순간적인 링크 레이트나 업로드 속도, 회선의 최대 용량을 뜻하지 않습니다.

01

현재 Wi-Fi에 연결

CoreWLAN에서 활성 인터페이스와 SSID를 확인합니다.

02

작은 다운로드를 세 차례 시도

각 요청은 실제 Wi-Fi 인터페이스에 묶어 다른 네트워크 경로가 측정을 대신하지 않게 합니다.

03

완료된 값만 기록

연결된 SSID가 측정 전후 동일한지 확인하고 성공한 다운로드 처리량의 중앙값을 표시합니다.
